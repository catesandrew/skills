# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
A mix of three audiences, with no single primary one confirmed (the split is an open decision):
- Developers using Claude Code, Codex or similar agents who browse the catalog to pick a skill to install and learn how it behaves.
- Skill authors who read the site as a reference for skill format, structure and quality bar.
- Peers, recruiters or clients who see it as a showcase of the owner's work.

## Product Purpose
Documentation site for `catesandrew/skills`, a public, stack-agnostic collection of cross-agent skills published both as an Agent Skills library (`skills` CLI) and a self-hosted Claude Code plugin marketplace. Success: a visitor finds the right skill, understands what it does and why it exists, and installs it.

## Positioning
Each skill has a deep-dive page grounded in real history: what it does, how to use it, gotchas and invariants, why it exists, related skills. A README listing cannot carry that depth.

## Operating Context
- Hosted at https://skills.catesworks.dev on Vercel; Docusaurus 3 (classic preset) in `website/`.
- `website/docs/skills-catalog.md` is generated by `bin/generate-skill-docs.mjs` from `skills/*/metadata.json` and `SKILL.md`; deep-dive pages in `website/docs/skills/` are hand-written and checked by `pnpm docs:check`.
- Install paths shown to visitors: Claude Code plugin marketplace (`/plugin marketplace add catesandrew/skills`, `/plugin install cw@skills`) and the `skills` CLI.

## Capabilities and Constraints
- Must stay on Docusaurus 3 classic and keep the generation and `docs:check` pipeline working.
- Must keep the `skills` name, the catesworks.dev domain and the Vercel deploy.
- Must keep light and dark modes, following `prefers-color-scheme`.
- Public repo: no employer, client or machine-path references (see AGENTS.md).
- The skill count is derived at build time from `skills/*/metadata.json` (see `website/skills-data.ts`); never hardcode it in copy.

## Brand Commitments
Name "skills"; sibling of the `next-starters` repo, which keeps the stack-coupled skills. No logo or palette is binding; the current logo and Docusaurus defaults are placeholders.

## Evidence on Hand
- 68 skills, each with a deep-dive page under `website/docs/skills/`.
- `.sessions/` dossiers documenting how the docs site and pages were built.
- Absent: testimonials, usage numbers, install counts, screenshots of skill output. Do not fabricate them.

## Product Principles
1. The deep-dive pages are the product; navigation and design serve reading and finding them.
2. Every claim is traceable to the repo (counts, install commands, skill behavior).
3. Both install paths (plugin marketplace and `skills` CLI) stay equally visible.
4. Public-safe by default: nothing identifying an employer, client or machine.
5. Generated and hand-written content must stay in sync; design must not break the pipeline.

## Accessibility & Inclusion
No product-specific standard established. Light and dark modes are required.
