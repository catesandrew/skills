Add `app-hardening-audit`: a checklist-driven security and launch-readiness audit for web apps, with per-domain reference checks (auth, RLS, secrets, endpoints, headers, payments, cost, LLM and agent risks, privacy, operations, release, accessibility), 11 defensive stress-test scenarios, and a Pass/Fail/N/A report template. Checks are written from public standards (OWASP, Supabase, NIST, Stripe) and cited in `references/sources.md`.
